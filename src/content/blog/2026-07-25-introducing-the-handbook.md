Apoli can do a lot. It has over a hundred power types, and roughly as many actions and conditions again. Until now, learning it meant reading source code or piecing together half-remembered examples. The Handbook puts the JSON side and the Java side in one place.

## What's here

- The [data pack docs](/docs/datapack) are the JSON reference: powers, actions, conditions and data types, each with examples you can copy.
- The [addon docs](/docs/addon) cover the Java API, for when you're extending Apoli itself.
- Search covers both. Press <kbd>/</kbd> anywhere to open it.

## Origins is an addon

One thing I want the Handbook to make obvious: Origins is an addon for Apoli. Apoli is the engine that makes powers possible, and Origins is one very popular way to hand those powers out. Once you know Apoli, Origins is a thin layer on top.

## Kept up to date

The docs are written from the mods' source. When a power, action, condition or data type changes, its page is meant to change with it, so what you read here matches what's in the jar.

More pages are on the way. If something's missing or wrong, poke me on [Discord](https://discord.gg/) or [GitHub](https://github.com/0vergrown).
