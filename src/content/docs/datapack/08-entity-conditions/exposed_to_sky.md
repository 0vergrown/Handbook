Checks whether the entity is exposed to the sky, meaning the sky is visible from the entity's position.

Type ID: `apoli:exposed_to_sky`

## Fields

This condition has no fields.

## Examples

```json
"condition": {
    "type": "apoli:exposed_to_sky"
}
```
