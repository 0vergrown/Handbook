Checks whether the entity is swimming, meaning it is in the swimming pose.

Type ID: `apoli:swimming`

> [!NOTE]
> This condition only works on players.

## Fields

This condition has no fields.

## Examples

```json
"condition": {
    "type": "apoli:swimming"
}
```
