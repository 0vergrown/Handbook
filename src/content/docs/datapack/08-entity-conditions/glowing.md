Entity Condition Type

Checks if the entity is glowing either via the Glowing status effect, [apoli:entity_glow](/docs/datapack/powers/entity_glow) or [Self Glow (Power Type)](/docs/datapack/powers/self_glow).

Type ID: `origins:glowing`


## Fields

"condition": {
    "type": "origins:glowing"
