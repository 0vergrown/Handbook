Checks whether the entity is glowing, either from the Glowing status effect, from [apoli:entity_glow](/docs/datapack/powers/entity_glow) or from [Self Glow (Power Type)](/docs/datapack/powers/self_glow).

Type ID: `apoli:glowing`

## Fields

This condition has no fields.

## Examples

```json
"condition": {
    "type": "apoli:glowing"
}
```
