---
title: "Climbing (Entity Condition Type)"
description: "Checks whether the entity is climbing."
navigation_title: "Climbing"
---

Checks whether the entity is climbing, for example on a ladder or vines.

Type ID: `apoli:climbing`

## Fields

This condition has no fields.

## Examples

```json
"condition": {
    "type": "apoli:climbing"
}
```
