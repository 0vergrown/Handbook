Checks whether the entity is fall flying, which is gliding with an elytra, an elytra power or something similar.

Type ID: `apoli:fall_flying`

## Fields

This condition has no fields.

## Examples

```json
"condition": {
    "type": "apoli:fall_flying"
}
```
