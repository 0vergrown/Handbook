Entity Condition Type

Checks whether the entity is currently sprinting.

Type ID: `origins:sprinting`

!!! note

    **This entity condition type will only work on players.**


## Fields

_None._


## Examples

```json
"condition": {
    "type": "origins:sprinting"
}
```
