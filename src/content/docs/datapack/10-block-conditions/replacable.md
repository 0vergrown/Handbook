Checks whether the block is a replaceable material, which placing another block simply overwrites, such as tall grass or water.

Type ID: `apoli:replacable`

## Fields

This condition has no fields.

## Examples

```json
"block_condition": {
    "type": "apoli:replacable"
}
```
