---
title: "Attachable (Block Condition Type)"
description: "Checks whether a block that needs support could attach at this position."
navigation_title: "Attachable"
---

Checks whether a block that needs support, such as a torch or a button, could attach at this position. It passes when the side of any neighbouring block that faces this position is solid.

Type ID: `apoli:attachable`

## Fields

This condition has no fields.

## Examples

```json
"block_condition": {
    "type": "apoli:attachable"
}
```
