---

Checks whether the block is marked in code as blocking light. Glass, for example, doesn't pass.

Type ID: `apoli:light_blocking`

## Fields

This condition has no fields.

## Examples

```json
"block_condition": {
    "type": "apoli:light_blocking"
}
```
