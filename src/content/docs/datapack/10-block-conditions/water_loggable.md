Checks whether the block can be waterlogged, meaning a fluid can share its space, as it can with stairs.

Type ID: `apoli:water_loggable`

## Fields

This condition has no fields.

## Examples

```json
"block_condition": {
    "type": "apoli:water_loggable"
}
```
