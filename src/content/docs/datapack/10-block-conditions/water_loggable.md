Checks whether the block is waterloggable, meaning that there can be fluid in the same block space (e.g. stairs).

Type ID: `apoli:water_loggable`

## Fields

_None._

## Examples

```json
"block_condition": {
    "type": "apoli:water_loggable"
}
```
