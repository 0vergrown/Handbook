Power Type

Allows the player to swim (outside of water!).

Type ID: `origins:swimming`


## Fields

_None._



## Examples

```json
{
    "type": "origins:swimming",
    "condition": {
        "type": "origins:on_block"
    }
}
```

This example will make the player swim instead of sprint if the player is on the ground.
