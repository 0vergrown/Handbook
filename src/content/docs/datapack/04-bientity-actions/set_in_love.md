navigation_title: "Set In Love"
---

Puts the target entity into love mode, where it looks for another animal to breed with. It only works on animals that can breed, such as cows and pigs.

Type ID: `apoli:set_in_love`

## Fields

This action has no fields.

## Examples

```json
"bientity_action": {
    "type": "apoli:set_in_love"
}
```
