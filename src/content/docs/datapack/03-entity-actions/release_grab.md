Ends every active [grab](/docs/datapack/bientity-actions/grab) the entity is part of, whether it is the one grabbing or the one being grabbed.

Type ID: `apoli:release_grab`

## Fields

This action has no fields.

## Example

```json
"entity_action": {
    "type": "apoli:release_grab"
}
```
