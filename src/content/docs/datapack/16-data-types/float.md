A floating point (decimal) number, like `6.0`, `-1.5` or `0.1`.
## Example

```json
"condition": {
	"type": "apoli:relative_health",
	"comparison": "<=",
	"compare_to": 0.5
}
```

A Relative Health (Entity Condition Type) that has a `compare_to` float value of `0.5`.
