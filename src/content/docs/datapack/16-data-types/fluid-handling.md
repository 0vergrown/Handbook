A [String](/docs/datapack/data-types/string) that decides how raycasts treat fluids.

## Values

| Value | Description |
| --- | --- |
| `any` | The ray stops at both flowing and source fluids. |
| `none` | The ray ignores fluids. |
| `source_only` | The ray only stops at source fluids. |
