A [String](/docs/datapack/data-types/string) that picks the container layout for the inventory of an [apoli:inventory](/docs/datapack/powers/inventory) power.

> [!NOTE]
> This is different from [Inventory Type](/docs/datapack/data-types/inventory-type).

## Values

| Value | Description |
| --- | --- |
| `chest` | The inventory looks like a single chest. |
| `hopper` | The inventory looks like a hopper. |
| `dropper` | The inventory looks like a dropper. |
| `dispenser` | The inventory looks like a dispenser. |
| `double_chest` | The inventory looks like a double chest. |
