A list of values of another data type. It is enclosed in square brackets, with a comma between each element and the next.

## Examples

```json
"field_name": [
    "first",
    "second",
    "third"
]
```

An array of strings.

```json
"conditions": [
    {
        "type": "apoli:on_fire"
    },
    {
        "type": "apoli:sprinting"
    }
]
```

An array of entity condition types.
