A [String](/docs/datapack/data-types/string) naming one of a player's abilities.

## Values

| Value | Description |
| --- | --- |
| `minecraft:flying` | Whether the player is flying right now. |
| `minecraft:instabuild` | Whether the player can destroy blocks instantly. |
| `minecraft:invulnerable` | Whether the player is immune to all damage except "out of world" damage. |
| `minecraft:mayBuild` | Whether the player can place and destroy blocks. |
| `minecraft:mayfly` | Whether the player can fly. |
