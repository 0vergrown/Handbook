A [String](/docs/datapack/data-types/string) that decides how an item stack is processed, whether it is being modified or evaluated.

## Values

| Value | Description |
| --- | --- |
| `items` | The items of the matching stacks are modified or evaluated one at a time. |
| `stacks` | The matching stacks are modified or evaluated one stack at a time. |
