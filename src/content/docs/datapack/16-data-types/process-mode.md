A [String](/docs/datapack/data-types/string) that determines how an item stack is processed; be it either being modified or evaluated.

## Values

Value | Description
------|------------
`items` | The items of the matching item stacks are modified or evaluated individually.
`stacks` | The matching item stacks are modified or evaluated per stack.
