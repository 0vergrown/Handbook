A [String](/docs/datapack/data-types/string) used to pick one of the two vanilla player skin models.

##	Values

  Value    |  Description
-----------|------------------------------------------------------------------
  `wide`   |  The four-pixel arms, historically the "Steve" model. Also accepted as `default`, `classic` or `steve`.
  `slim`   |  The three-pixel arms, historically the "Alex" model. Also accepted as `alex`.
