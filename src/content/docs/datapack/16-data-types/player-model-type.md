A [String](/docs/datapack/data-types/string) that picks one of the two vanilla player skin models.

## Values

| Value | Description |
| --- | --- |
| `wide` | The four-pixel arms, known as the "Steve" model. `default`, `classic` and `steve` are accepted too. |
| `slim` | The three-pixel arms, known as the "Alex" model. `alex` is accepted too. |
