A whole number, like 3 or -1. Numbers such as 0.3 or 5.5 aren't allowed, because those are [Floats](/docs/datapack/data-types/float).

## Example

```json
{	
	"type":"apoli:set_on_fire",
	"duration": 3
}
```

An [apoli:set_on_fire](/docs/datapack/entity-actions/set_on_fire) with a `duration` of 3, which is a whole number.
