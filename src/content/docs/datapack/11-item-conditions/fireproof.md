Checks if the item stack is fireproof.

Type ID: `apoli:fireproof`

## Fields

_None._

## Examples

```json
"item_condition": {
    "type": "apoli:fireproof"
}
```

> **`apoli:fire_resistant` is this condition,** kept as an alias for packs ported from the original Apoli.
