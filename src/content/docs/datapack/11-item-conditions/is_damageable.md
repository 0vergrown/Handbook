Checks if the item is damageable.

Type ID: `apoli:is_damageable`

## Fields

_None._

## Examples

```json
"item_condition": {
    "type": "apoli:is_damageable"
}
```

> **`apoli:damageable` is this condition,** kept as an alias for packs ported from the original Apoli.
