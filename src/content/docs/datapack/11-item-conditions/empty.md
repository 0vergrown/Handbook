---
title: "Empty (Item Condition Type)"
description: "Checks whether there is no item at all."
navigation_title: "Empty"
---

Checks whether there is no item at all, such as an empty slot.

Type ID: `apoli:empty`

## Fields

This condition has no fields.

## Examples

```json
"item_condition": {
    "type": "apoli:empty"
}
```
