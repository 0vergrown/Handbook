Bi-entity condition types check a pair of entities, an actor and a target. The power or condition that uses them decides which entity is which, and [`apoli:invert`](/docs/datapack/bientity-conditions/invert) swaps the two. They can go in any power or condition type that has a `bientity_condition` field.

Every bi-entity condition type is listed in this section.
