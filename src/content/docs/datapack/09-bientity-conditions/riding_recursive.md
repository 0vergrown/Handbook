Checks whether the actor is riding the target, wherever the target is in the riding stack below it.

Type ID: `apoli:riding_recursive`

## Fields

This condition has no fields.

## Examples

```json
"bientity_condition": {
	"type": "apoli:riding_recursive"
}
```
